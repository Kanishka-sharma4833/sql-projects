# Zepto SQL Data Analysis Project

## 📌 Project Overview

This project focuses on analyzing Zepto's grocery and e-commerce dataset using SQL. The objective is to explore product information, pricing, discounts, stock availability, and product categories to generate meaningful business insights.

## 🎯 Objectives

- Analyze the Zepto product dataset using SQL.
- Understand product categories and product availability.
- Analyze MRP, discount percentage, and discounted selling price.
- Identify products with high and low discounts.
- Analyze stock availability and out-of-stock products.
- Perform data exploration and aggregation using SQL queries.
- Generate useful insights for business decision-making.

## 📂 Dataset

The dataset contains information about Zepto products, including:

- SKU ID
- Category
- Product Name
- MRP
- Discount Percentage
- Available Quantity
- Discounted Selling Price
- Weight in Grams
- Out-of-Stock Status

## 🛠️ Tools & Technologies

- SQL
- PostgreSQL / MySQL
- GitHub
- CSV Dataset

## 🔍 SQL Analysis Performed

The project includes SQL queries for:

1. Data exploration
2. Total number of products
3. Category-wise product analysis
4. Price analysis
5. Discount analysis
6. Stock availability analysis
7. Out-of-stock product analysis
8. Highest and lowest priced products
9. Products offering the highest discounts
10. Category-wise business insights

## 📊 Key Insights

The analysis helps understand:

- Which categories contain more products.
- Products with the highest discounts.
- Products with high MRP.
- Availability of products in different categories.
- Pricing patterns across products.
- Stock and out-of-stock conditions.
